Privacy Policy / プライバシーポリシー

Last updated: 2026-11-24

yt-auto is an internal automation tool used only by the owner of the channel it uploads to. It is not offered to the public.

Data accessed

With the owner's OAuth authorization, the tool uses the YouTube Data API only to upload videos to the owner's own channel (scope youtube.upload) and to confirm the authorized channel name (scope youtube.readonly, channels.list with mine=true). It does not access any other user's data.

Data stored

Only the IDs of videos uploaded by the tool are stored, in the owner's private GitHub repository, to link to the videos for review. OAuth credentials are stored only as encrypted GitHub Actions secrets. No personal data of viewers or other users is collected.

Data sharing

No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

日本語

yt-auto は、アップロード先チャンネルの所有者だけが使う内部用の自動化ツールで、一般には提供していません。所有者の許可（OAuth）のもと、所有者自身のチャンネルへの動画アップロード（youtube.upload）と、許可したチャンネル名の確認（youtube.readonly）のためだけに YouTube Data API を使います。他のユーザーのデータにはアクセスしません。

保存するのはアップロードした動画のIDのみで、所有者の非公開リポジトリに保存します。認証情報は GitHub Actions の暗号化された Secrets にのみ保存します。データの販売・第三者提供・広告利用は行いません。アクセス権は Google アカウントの設定からいつでも取り消せます。
